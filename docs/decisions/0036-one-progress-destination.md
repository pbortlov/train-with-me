# 0036 - One Progress destination

- Date: 2026-10-24
- Status: accepted

Progress remains one destination, but athletes can focus the review on Strength,
Running, or Sprint with an activity switcher. The switcher only changes which
activity cards are foregrounded; it does not merge unlike metrics or alter
stored workout data.

Strength review starts with an all-exercise index. Each row is identified by
exercise name, variation, equipment, and load type. Selecting a row opens its
details inline so the selected exercise, exact logged sessions, saved kg target,
and pending suggestion remain visually connected on a phone screen. Exercises
without saved targets remain discoverable, and pain-affected or otherwise
non-comparable work remains visible with an exclusion label.

Running and Sprint keep their existing domain metrics and detailed analytics.
When there is no history, the activity view explains what to log and provides a
direct action to start that activity. Chart evidence is available on demand;
existing filters and calculations remain unchanged.

This decision changes the review presentation only. It does not change what
counts as comparable work, how progression is calculated, or how workouts and
targets are stored.
