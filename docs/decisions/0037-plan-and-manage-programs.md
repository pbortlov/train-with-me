# 0037 - Plan and Manage programs

- Date: 2026-10-24
- Status: accepted

The athlete-facing planning destination is named **Plan**. It combines the week
calendar with a compact active-program context card showing the scheduled
program, lifecycle status, planned-session count, and current program week.

Program setup and advanced controls live under a separate **Manage** destination.
Manage keeps scheduled programs visible first, while saved templates and their
import/export, filtering, duplication, editing, scheduling, and builder controls
remain available on demand. Manage provides a direct route back to Plan.

This is a presentation and navigation decision. It preserves existing calendar
movement, generated-session identity, program-week calculations, template
refresh behavior, local storage, and backup contracts.
